# MyBudget macOS app

SwiftUI client for the MyBudget server. It talks to the server over HTTP, using the same API a future web client will use.

To create the project: in Xcode, choose File › New › Project › macOS › App (Interface: SwiftUI), name it `MyBudget` and save it in this folder.

The app is outside the adversarial loop: neither agent can write here.
